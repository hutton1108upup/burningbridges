# 登录弹窗优化

日期：2026-10-13。基于已合并视频生成工作的最新 `main`，本次仅修改账号界面与其交互，保留现有认证、付款与生成接口。

## 完成内容

1. 登录：Google 可用时在上方显示带标识的按钮；邮箱密码直接展开；一个主提交按钮，注册和找回使用文字链接。
2. 注册：独立标题、创建密码标签、12–128 字符提示，以及已有账号的登录入口。
3. 恢复：隐藏 Google、分隔线和邮箱，明确使用保存的恢复码与新密码，不声称发送了重置邮件。
4. 保存恢复码：提供复制、复制受限时的手动选取、下载和保存确认；恢复后使用服务器返回的账号邮箱，避免下载文件写入旧的表单邮箱。
5. 关闭移到右上角；密码支持显示/隐藏；状态切换保留邮箱，清除密码、恢复码和错误；关闭后清除敏感内容。
6. 提交期间禁用重复操作及关闭，结束或失败后恢复；浏览器返回 OAuth 前页面时恢复可操作状态。保留套餐选择后的登录回调和照片草稿流程。
7. 对话框有可访问标题、说明、错误提示及焦点；登录、注册、恢复和保存状态均沿用原有录屏屏蔽。

- `npm run deploy:dry-run`：构建与 Worker 打包通过；这是模拟检查，不是生产部署。

- 以本地拦截接口验证注册与恢复成功、登录错误和重试、请求期间禁止重复操作及 Escape 关闭、恢复码复制与下载，以及复制受限回退。
- 单独检查选择套餐后完成登录，付款入口按原套餐继续一次。全部使用本地测试响应，不调用真实付款、Google 授权或 AI 服务。

浏览器回归脚本为 `scripts/qa-auth.cjs`，需要 Playwright 运行环境；可通过 `PLAYWRIGHT_MODULE` 指定工具环境提供的模块，`AUTH_QA_ORIGIN` 指定本地预览地址。脚本只接受本机 HTTP 地址，输出与截图写入忽略提交的 `.local/`。
